## 🛠 Comment intégrer une image que tu fournis

1. Place le fichier dans le bon sous-dossier de `public/media/`.
2. Dans le fichier de données concerné (`src/data/*.ts`), remplace l'objet `media: { placeholder, desc }` par :

```ts
media: {
  src: '/media/pc-family/channel.png',
  alt: 'Chaîne YouTube PC Family',
  ratio: '16 / 9',
}
```

3. Modifie `src/components/MediaPlaceholder.tsx` pour afficher une `<img>` quand `src` est présent (modification simple).
4. Pour les vidéos (PC Family, démo IA) : mets l'URL dans le champ `link` du projet correspondant dans `src/data/projects.ts`.
